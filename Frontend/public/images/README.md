## Image Asset Structure

- `branding/logos`
  Store logos, brand marks, wordmarks.

- `branding/icons`
  Favicons and small brand-specific icons.

- `categories`
  Category thumbnails and icon-style images used in category cards and hero sections.
  Recommended structure: one folder per category, e.g. `categories/fruits/thumbnail.png`.

- `products`
  Product packshots and item images used in product cards, listings, and product detail pages.

- `mockups`
  UI references, screenshots, and design inspiration files. These should not be used directly in production UI unless intentionally cropped/exported.

- `placeholders`
  Temporary fallback assets for incomplete sections.

### Naming Tips

- Use descriptive lowercase names like `amul-milk.png`, `whole-wheat-bread.png`, `fresh-banana.png`.
- Avoid timestamp file names for long-term project assets.
- Keep one product per file and prefer transparent or clean white backgrounds.
