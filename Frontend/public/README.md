## `public` Structure

- `images/branding`
  Brand logos, favicons, and icon assets.

- `images/categories`
  Category thumbnails used by category cards and hero sections.

- `images/products`
  Product packshots and product display images.

- `images/mockups`
  Design references and screenshots. Keep these out of production UI unless intentionally cropped/exported.

- `images/placeholders`
  Temporary fallback images for incomplete sections.

- `documents`
  PDFs and downloadable brand or project documents.

### Guidelines

- Keep the `public` root minimal.
- Put all visual assets into named folders instead of dropping files at root.
- Use lowercase descriptive filenames like `banana-packshot.png` or `checkout-reference.png`.
- Treat `mockups` as reference material, not final UI assets.
